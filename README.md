# Proyecto 2D - Base

Este proyecto es una plantilla y práctica base desarrollada en el motor Godot Engine 4 para el desarrollo de videojuegos en 2D.
Incluye la configuración de la escena principal (`main.tscn`) con cámara ortográfica `Camera2D` y mapeo de acciones de entrada.
El sistema de controles tiene mapeadas las acciones básicas: `move_left`, `move_right`, `jump` y `pause`.
Se han integrado recursos externos con licencias permisivas organizados dentro del directorio estructurado `assets/`.
El control de versiones se gestiona mediante Git siguiendo buenas prácticas de documentación y registro de cambios.
